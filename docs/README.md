# Phosphor documentation

How Phosphor works, for people drawing with it.

- [Layers](layers.md) — the base layer (your image, converted to cells) and the edit layer
  (everything you draw): merging up and down, erasing, and what the Select tool acts on.
- [Characters](characters.md) — what a cell can hold, one- and two-column characters (Chinese,
  Japanese, Korean, emoji), typing any script, pasting text, and saving as .utf8ans or .ans.
- [Social](social.md) — the SOCIAL tab: the lobby, accounts and guests, hosting a room and watching
  someone draw, chat, blocking and reporting, and what isn't in this version yet.

The colors: the picker at the right of the tab bar (a moon, a sun and a computer display) chooses
**Dark** (the default), **Light** or **System** (which follows your computer's setting, and changes
when it does). Your choice is kept in this browser. A narrow window has no room for it there, so it
stays on your last choice (Dark to begin with).

The address: the address bar says which tab you're on and, on SOCIAL, which page, so Back and Forward
move between them and a reload comes back to the same place. ANSI and SAUCE need an image: with none
open, their addresses show PIXEL. A narrow window has no SOCIAL tab, so its address shows PIXEL too.
What the address does in a room is under [Social](social.md).
